# Estudos e Fundamentos de Python 🐍

Este repositório centraliza mais de 50 scripts, rotinas e exercícios práticos desenvolvidos durante os meus estudos da linguagem Python. O objetivo é consolidar uma base sólida em lógica de programação, estruturas de dados e os pilares da engenharia de software back-end.

##  Tecnologias e Ferramentas
- Python 3
- VS Code
- Git / GitHub

##  O que você encontrará neste repositório?
Os arquivos cobrem uma trilha completa de aprendizado fundamental:

- **Lógica de Programação Básica:** Estruturas condicionais (`if/elif/else`), laços de repetição (`for`, `while`) e manipulação de strings.
- **Estruturas de Dados:** Implementações práticas de listas, pilhas (Stacks) e filas duplas (Deques) para organização de dados na memória.
- **Tratamento de Exceções e Erros:** Manipulação robusta de fluxos com blocos `try/except/finally` e leitura/escrita de arquivos locais (.txt e .csv).
- **Orientação a Objetos (POO):** Criação de classes, métodos, encapsulamento e modelagem de entidades.
